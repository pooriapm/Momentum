# Official source register

Verified on: **2026-08-03**
Review owner: Product + Engineering + Legal
Next scheduled review: before any public launch and at least quarterly thereafter

This register contains the primary or official sources used in Momentum's product, pricing, safety, data, and AI decisions. Market prices and vendor policies can change; a dated source check is a launch requirement.

## OpenAI platform and policy

- [OpenAI API supported countries and territories](https://help.openai.com/en/articles/5347006)
  - Material fact at review date: Iran was not listed. The page says access or offering access outside listed locations may result in blocking or suspension.
- [OpenAI Usage Policies](https://openai.com/policies/usage-policies/)
  - Tailored advice that requires a license, including medical advice, requires appropriate involvement by a licensed professional.
  - Policies also address minors, disordered eating, privacy, and high-stakes automated decisions.
- [OpenAI API pricing](https://developers.openai.com/api/docs/pricing)
  - Source for current standard, cached, Batch, and Flex token prices.
- [Using the latest OpenAI model family](https://developers.openai.com/api/docs/guides/latest-model.md)
  - At review date: GPT-5.6 Sol is the flagship; Terra balances intelligence and cost; Luna targets high-volume, cost-sensitive work.
- [Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)
- [Flex processing](https://developers.openai.com/api/docs/guides/flex-processing)
- [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)
- [Safety best practices](https://developers.openai.com/api/docs/guides/safety-best-practices)
- [Under-18 API guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance)
- [Data controls and retention](https://developers.openai.com/api/docs/guides/your-data)
  - API data is not used for training by default, but default abuse-monitoring retention can be up to 30 days. Zero Data Retention requires eligibility and approval.
- [Project rate limits and spend alerts](https://developers.openai.com/api/docs/guides/terraform/rate-limits-and-spend)
  - Spend alerts notify; they are not hard caps.

## Interpretation rule

Facts directly stated by these sources are labelled **Source-backed** in Momentum documents. Product choices, forecasts, usage assumptions, prices, and margin targets are labelled **Momentum hypothesis** or **Momentum policy** and must be validated with product data and professional review.
